# Lobby reference art

The lobby image crops in `public/assets/lobby-reference/` come from the user-provided `E:\Image\Ảnh nền máy tính\Web_Photo_Editor.jpg` (1920 × 1081). Recreate them with `python tools/extract-lobby-reference-art.py`.

These are illustrative reference crops for the lobby dashboard: the character, apartment, boss, AI butler, reward thumbnails and sidebar city. They are not screenshots of the player's saved 3D apartment or avatar. The dashboard labels, task progress, Gold, character stats and finance values come from current game state. “Vào căn hộ 3D” opens the real Home world.
